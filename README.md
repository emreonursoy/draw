# draw

A hand-drawn style whiteboard built with Next.js, React and roughjs.

```bash
npm install
npm run dev     # http://localhost:3000
```

Press `?` in the app for all keyboard shortcuts. Scenes autosave to localStorage; File > Save writes a `.draw` JSON file (compatible `.json` files can also be opened and exported).

Not implemented: live collaboration, server sync, accounts (everything stays in your browser). Slides can be exported to PDF; PPTX export and AI features are intentionally left out.
